# 光格突圍 Light Grid Escape

原創繁體中文網頁遊戲，靈感來自 LED 感應地磚闖關（看清燈號、找路、抓時機）。玩家控制光能機械人逐格走過霓虹密室，收集藍色能量、避開紅格，出口開啟後走進出口過關。不使用任何品牌名稱、標誌、素材或專有關卡。

公開網站：https://lphky.github.io/light-grid-escape/

## 玩法

- 綠色盾牌格永遠安全；藍色菱形格收集能量；琥珀斜紋＝即將變紅；紅色交叉格碰到扣一命；白紫色門形＝出口。
- 每關三命，受傷後一秒保護；停在紅格保護結束仍會再受傷。生命或時間用完即失敗。
- 剛收集能量的那一格，在玩家離開前不會變紅（避免「能量在紅線中間」的陷阱）。
- 第四關起解鎖衝刺：向前兩格、冷卻三秒、沿途每格判定、沒有無敵效果。
- 評價：★ 過關；★★ 受傷不多於一次；★★★ 無傷並在該關挑戰時間內完成。分數＝能量×100＋剩餘生命×200＋剩餘整秒×10。
- 模式：闖關、練習（不限時、不計分、不寫紀錄）；輔助設定（機關速度 75%、預警相應加長、隱藏能量一直顯示，成績另存，仍可解鎖）。

| 8 | 節奏方陣 | 兩組方塊按節拍輪流開關 |

## 檔案

- `index.html`、`style.css`：介面及版面（桌面、手機直／橫向、左手配置）。
- `src/engine.mjs`：純邏輯遊戲引擎（固定步長 1/60 秒、移動、衝刺、機關、傷害、計分），無 DOM。
- `src/levels.mjs`：十二關資料；機關類型 `static`、`pulse`、`mover`、`rotor`。
- `src/render.mjs`：Canvas 繪製；`src/app.mjs`：選單、輸入、迴圈、結算；`src/audio.mjs`：Web Audio 合成音效及音樂；`src/storage.mjs`：localStorage 存檔（帶版本、可容錯）。
- `tests/engine.test.mjs`：規則及存檔測試；`tests/solver.mjs`：以真實引擎逐幀模擬的自動解關程式，驗證每關可無傷完成。

## 開發

純 HTML／CSS／JavaScript（ES modules），無建置步驟、無外部依賴。本機以任何靜態伺服器開啟，例如 `python3 -m http.server`。

測試：`node --test tests/*.test.mjs`

網址加 `?debug` 會在 `window.__lightGrid` 暴露遊戲狀態，只供測試。
